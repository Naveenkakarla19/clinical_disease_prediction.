# clinical_disease_prediction.
An end-to-end Machine Learning pipeline predicting early cardio-metabolic disease risk from patient clinical biomarkers (BP, Glucose, BMI, Cholesterol). Using Gradient Boosting, the model delivers 91.47% accuracy, 91.04% recall, and 0.961 ROC-AUC for preventive triage, directly supporting UN Sustainable Development Goal 3: Good Health and Well
